如何在线比较文本（3 个简单步骤）

1

输入或上传文本

将原文粘贴到左侧面板，修改后的文本粘贴到右侧面板，或直接将文件（.txt、.json、.js、.md）拖放到输入框。

2

自定义选项

切换忽略空白、大小写敏感性或行号显示。在分栏视图和统一视图之间切换，或选择词/字符差异粒度。

3

查看 & 导出结果

使用差异步进器（Alt+N / Alt+P）或搜索栏在修改处之间跳转，然后导出补丁文件或复制报告。

常见问题

我的数据安全和保密吗？

是的。所有差异计算都在您的浏览器本地进行。不会有任何文本或文件内容发送到外部服务器。

我可以比较格式化的 JSON 文件吗？

当然！点击任一编辑面板上的"格式化 JSON"按钮，即可在比较前将原始 JSON 字符串格式化为美化打印的结构。

支持哪些导出格式？

您可以导出兼容 Git 的统一补丁（.patch）文件、可下载的 HTML 可视化差异报告，或 JSON 元数据对象。

有键盘快捷键吗？

有！按 Alt+N 跳转到下一处差异，Alt+P 跳转到上一处差异，Alt+S 交换面板，Alt+E 打开导出选项。
